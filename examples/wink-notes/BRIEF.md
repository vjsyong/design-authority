# wink-notes — app brief

A small ritual-notes app: one page with a list, an add form, and a save flow.
Built under **wink 0.2.0** through the project workflow (`da init` → `da plan`
→ build → receipt → verify → reconcile). This app is the end-to-end
acceptance vehicle for the consumer workflow (docs/13 P1.1/P1.2).

## Needs

- a primary action button
- an inline notice confirming a save
- an empty state when no rituals exist
- a progress readout for saving
- a floating toast notification
