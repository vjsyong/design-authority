01 · The promise

Stop teaching every coding agent your design from scratch.

Agents may improvise. They may not confuse improvisation with authority.

Design Authority turns your existing screens, brand kits, and design decisions into a shared standard that AI coding agents can follow. Agents stay consistent, show where they improvise, and bring new decisions back for human review. The standard evolves without losing its history.

03 · How it works

How a Design Authority is created, used, and evolved.

  1. 1Compile

    Evidence becomes reviewed rules.

  2. 2Govern

    Agents build, consult and verify.

  3. 3Evolve

    New cases become reviewed precedent.

1. COMPILE
PRECEDENT

existing product · brand kit · cases

↓
MACHINE

extracts evidence + infers norms

↓
HUMAN GATE · INTERPRETATION

accept · modify · reject · leave open

↓
release
DESIGN AUTHORITY

published, versioned standard · everything downstream cites it

↓
2. GOVERN
AGENTS BUILD

resolve · compose · improvise visibly; never silently canonized

↓
VERIFY

↓
3. EVOLVE
CASES

gaps · conflicts · proposals · fails

↓
HUMAN GATE · AMENDMENT

adjudicate what should change

↓
RELEASE + PRECEDENT

patch or fresh freeze, with reasons on record

The release merges back into the authority. That is the loop.

Machines assemble the evidence. Humans decide what becomes authoritative.
04 · The difference

What happens when authority has no answer?

Nothing is silently invented. A single need, tracked through the whole loop, from a build that had to improvise to the rule that stops the next build from guessing.

  1. ask

    Building the tracker under the Dominion authority, the agent needs paging for older entries.

  2. authority is silent

    resolve "pagination for older entries" → UNDEFINED. There is no paging canon, and inventing one silently is not allowed.

  3. improvise visibly

    The build ships outline buttons plus a plain readout. The decision is marked as noncanonical, like every unrecorded decision in the stress builds.

  4. gap filed

    gap/20261007-150030-e4273f lands in the workspace ledger.

  5. human adjudication

    Review finds partial evidence and no live-product instance. The outcome is neither canon nor discarded; it is ruled a provisional candidate with a promotion bar.

  6. memory

    Today the same ask still returns UNDEFINED, with Paging composition (provisional) attached, and the bar it must meet to become canon. The next build inherits the outline without mistaking it for authority.

Improvised work stays visibly noncanonical: in the Cadence builds every element outside authority carries a mark and a filed gap; the ◌ toggle reveals them. See one live.

Nothing was silently invented, and nothing was lost.

Limits

Level 2 conformance is partial and declared per component. Levels 3 and 4 are proposed. Nobody has yet shown that compliant builds behave better in users' hands. That experiment is next. An authority is not a Figma library, not a lint config, and not a way to lock people in.

Under the hood

In precise terms, a design authority is a versioned, machine-readable record of an interface system. Implementation agents are instructed to resolve decisions against the authority, while independent verification checks observable conformance. Decisions that would otherwise happen by default get written down, cited, and versioned.

packs/triage/
  authority.json      identity · version · consumers
  artifacts.json      80 records: components, token sets, patterns, guidelines
  rules.json          19 enforceable rules (TDS001–015 + interaction)
  golden.json         53 calibration cases: ask, expected, got
  verification.json   claims a verifier can test against a build
  AGENT-PROMPT.md     the consumption protocol for coding agents

The resolver

resolve "a switch" → component/px-sw

resolve "rounded corners on the cards" → CONFLICT (do not implement as requested)

OutcomeFires whenThe build does
RESOLVED the element matches a recorded artifact build it the recorded way
COMPOSE the element combines recorded parts assemble only in recorded ways
FALLBACK the environment cannot support the primary answer follow the recorded degradation
UNDEFINED authority has no answer implement locally if necessary, mark it as noncanonical, keep the provenance, and file the gap. Never present it as canon
CONFLICT the request contradicts a prohibition stop and escalate; do not implement as asked

Two consumers, one record

  1. 1Resolve

    Implementation agents are instructed to resolve decisions against the authority.

  2. 2Build

    The implementation follows the records. Deviations are choices, and choices are recorded.

  3. 3Verify

    Independent verification checks observable conformance. Agent self-report is evidence, not proof.

  4. 4Report

    Conformance comes back per rule with its evidence. A score is a gate, never proof.

  5. 5Adjudicate

    Conflicts and gaps become precedents and versions, not lost threads.

Every pass leaves a traceable decision, even when the authority itself remains unchanged.

Verification levels

LevelChecksStatus
L1 · Statictokens, selectors, declarations, structureshipped
L2 · Behaviouralkeyboard, focus restoration, state transitions, lifecyclepartial, declared per component
L3 · Renderedscreenshots, overflow, zoom, dark mode, reduced motionproposed
L4 · Productreal workflows: task success, error recovery, comprehensionproposed

Every conformance claim cites its rule, its implementation, and its evidence. The proposal lives in the Triage repository, at spec/proposals/verification-levels.md.

Version mechanics

Editorial edits ship as patches

Wording, examples, and citations ship as 0.1.x patches, with no re-freeze.

Semantic changes get a fresh freeze

Changes to pipeline order, thresholds, or record formats get a fresh freeze at 0.2 and up. A build is always checkable against the authority it was built on.

Reversals become precedents

When a decision is overturned, the reversal is recorded with its reason and cited by id. Nothing is quietly overwritten.

Ambitions wait in candidates

An idea enters with the condition that would promote it. Scope grows by evidence, not enthusiasm.
