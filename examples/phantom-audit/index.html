How to read this

Every finding below is in one of seven postures. canon the deployed language defines it — the review uses it as is. base a template value the deployment left untouched (still live). override a deployment change — canonised where deliberate, recorded where risky. candidate a promotion dossier with a bar to clear. improvised the system is silent — built in character, marked, filed. gap recorded for the owner; nothing invented silently. defect a plain bug — named, not designed around.

The site under review is a working notebook — unfinished by its own admission — and that is the honest context for every ledger item. Nothing on the reviewed site was modified: the audit is evidence, not a rewrite.
