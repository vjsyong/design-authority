How to read this

Every finding below is in one of five postures. canon the system defines it — the build uses it as is. candidate a provisional direction with a promotion bar, not authority. improvised the system is silent — built in character, marked, filed. gap recorded for the owner; nothing invented silently. defect a plain bug — fixed, not designed around.

The site under review is a working notebook — unfinished by its own admission — and that is the honest context for every item in the ledger. Nothing here was repaired: the audit is evidence, not a rewrite.
