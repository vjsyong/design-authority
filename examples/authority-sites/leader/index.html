Notice (ruled box)

Guidelines5 records

GUIDELINEguideline/hierarchy

Section rhythm

Section label (sans caps, red) → serif headline → one-line standfirst (muted serif). Repeats strictly; no decorative sub-heads.

GUIDELINEguideline/typography

Typography (three registers)

Three registers by role: Serif = headlines and body text; Sans = navigation, metadata, datelines, captions; Sans Headline = display-only moments (page mastheads, big statics), used sparingly.

GUIDELINEguideline/motion

Motion

Interaction transitions are near-instant (≤0.15s colour swaps); no bounce, spring or decorative movement in UI chrome. Motion stays native to brand assets, not interface controls.

GUIDELINEguideline/shape-language

Shape language (rounded product)

The live product uses soft rounded corners throughout: interactive components (buttons, toggles, inputs) and container surfaces (cards, panels) all carry radius ~8. Only rules, hairlines and editorial glyph marks stay crisp — no square buttons, no square cards.

GUIDELINEguideline/surfaces

Surfaces & separation

White ground; separation via 2px ink rules and hairlines below (wash separation removed per review). Elevation, where needed, uses defined shadow tokens — not ambient glows.

Patterns2 records

PATTERNpattern/data-charts

Data charts (rectilinear register)

Charts are rectilinear and editorial: ink bars on hairline baselines (2px ink origin rule, grey/ink gridlines), a month grid of square cells, and a hairline sparkline. Red appears only as a single accent; no rings, no decorative chart styling.

PATTERNpattern/data-readouts

Data readouts (sparkline trend, stat counter)

Big statics: an Archivo (display) numeral with a sans-caps label beneath; reserved for year-to-date totals and headline counts.

Token sets2 records

TOKEN SETtoken-set/colour

Colour roles (red + Chicago blue)

Red #E3120B = brand/editorial punctuation (labels, rules, single blocks). The Chicago blue family = the interactive layer (CTAs, active nav, links) — copious, per live review. Frame: ink, white, London grey ramp.

TOKEN SETtoken-set/type-scale

Screen type scale

Screen rhythm: serif headline 30–34/1.15; standfirst sans? no — serif standfirst 16–17 muted; body serif 17/1.55; metadata sans 12.5–13 with 0.06em caps for section labels; display 44 at tracking −1.

Specification

Rules, prohibitions, fallbacks

What the authority enforces, and where it leaves room. Requests resolve in order: CONFLICT → RESOLVED → COMPOSE → FALLBACK → UNDEFINED.

Rules2 recorded

ErrorL-R1 · severity: error

Interactive components and container surfaces are soft-rounded (radius ~8); only rules, hairlines and glyph marks stay crisp.

Fix: Give the component the system radius; remove square interactive corners.

WarningL-R2 · severity: warning

Red is brand/editorial punctuation; the Chicago blue family carries the interactive layer; frame is ink/white/London grey.

Fix: Map the colour to the nearest family token.

Prohibitions5 recorded · 4 shown

prohibit/square-interactiveSquare-cornered interactive components or cards — the live system is rounded (L-02, L-24).

prohibit/red-reading-surfaceRed as a reading background (L-24).

prohibit/decorative-noiseEmoji and exclamation marks (L-24).

prohibit/ambient-glowAmbient glow shadows — elevation uses defined shadow tokens only (L-24).

Each prohibition resolves as CONFLICT, citing its governing rule. Four were surfaced by direct conflict probes for this page; the recorded set holds five.

Fallbacks3 recorded

Interstitials become ruled panelsfallback/ruled-panel

No dialog canon: interstitials render as plain ruled panels in the page flow (L-07); mark the improvisation.

scope: dialog · modal · overlay · popup · interstitial · wizard · onboarding

Selection beyond small setsfallback/selection

Small sets use a native select styled like a field; larger or filtered selection uses the platform default, marked.

scope: select · dropdown · picker · combobox · listbox · filter

Platform defaults for uncovered controlsfallback/platform-controls

If the system defines no control for a need, use the platform's native element with the leader field styling; keep native semantics.

scope: checkbox · radio · date · toggle · switch · slider · stepper
