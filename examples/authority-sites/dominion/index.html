Guidelines · 3

guideline/typography · compiled from D-03

Typography (one family)beta

One family (Helvetica-class stand-in: Arimo), weights as roles: Light = quiet formal accents, Regular = default text, Medium = headings and key labels (web role per the standard), Bold = reserved for signage-style emphasis (rare).

guideline/bilingual · compiled from D-09

Bilingual pairingsbeta

The signature structural device: primary page titles and key labels render bilingually (English | French, side-by-side, thin divider; over-under when narrow). Body content stays in the app's own language. Where a string exists in one language only, no signposting line is fabricated (that rule governs official publications, not this derived app) — carried as system nuance.

guideline/interaction-states · compiled from D-21

Focus & interaction statesbeta

Focus does change colour: blue glow — 1px #66AFE9 outline + 8px rgba(102,175,233,.6) halo (live-measured on Canada.ca). Exclusive to focus; reads on any ground.

token-set/colour · compiled from D-05

Colour roles (ceremony + web layer)beta

FIP red strictly for ceremony: masthead accent device, the single primary action, identity zone marks. Black = text/structure; white = ground; pewter = de-emphasis (metadata, secondary labels). Status and errors are NOT colour-coded (see D-10).

Rules · 2

D-R1 · severity warning · applies to css, html

web-layer-interaction

Interactive layer follows the live web layer: slate actions (#26374A, radius 4), blue focus glow (#66AFE9), soft borders.

why: Live measurements on Canada.ca accepted at Gate 2 (D-01, D-11, D-21). · fix: Use the measured slate/blue values for interactive elements.

D-R2 · severity warning · applies to css, html

ceremonial-red

FIP red is ceremony only — never status, errors, or reading surfaces.

why: FIP standard + Gate 2 (D-05, D-22). · fix: Remove red from status/error/background roles.

Fallbacks · 2

fallback/platform-controls

Platform defaults for uncovered controls

If the system defines no control for a need, use the platform's native element with the field styling; keep native semantics.

constraints: field styling (soft border, radius 4) · blue glow focus · mark the improvisation and report a gap

fallback/large-selection

Selection beyond small sets

Small fixed sets use the select; larger or filtered selection uses the platform default, marked.

constraints: keep field styling · mark the improvisation
