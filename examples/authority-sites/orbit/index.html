Orbit Interface System

Version 0.1.0 — A minimal interface system derived from the NASA Graphics Standards Manual (1976) for the Design Authority portability spike. Carries no NASA marks.

Provenance: derived from the public-domain NASA Graphics Standards Manual (NHB 1430.2, 1976); this system carries no NASA marks.

Specification

What the authority declares — policy, rules, prohibitions, fallbacks (Orbit v0.1.0).

Policy

AspectPolicy (verbatim)
On conflict “Do not implement as requested; the request violates an explicit constraint (see the cited rule/prohibition).”
On undefined “Implement per the consuming project's fallback policy, mark the improvisation, and report a gap. Never present improvisation as canonical.”
Proposals “Noncanonical. The authority is never modified by a consumer; proposals are reviewed upstream.”
