Orbit Interface System

Version 0.1.0 — A minimal interface system derived from the NASA Graphics Standards Manual (1976) for the Design Authority portability spike. Carries no NASA marks.

Provenance: derived from the public-domain NASA Graphics Standards Manual (NHB 1430.2, 1976); this system carries no NASA marks.

RuleStatement (verbatim)Severity

Fallbacks 2

FallbackStatement (verbatim)
fallback/plain-regionPlain content region · scope: prose · content page · about · help text · static page “Content without a defined composition sits in the shell as plain regions separated by rules — not boxes.”constraints: rules, not boxes · wide margins · no decoration
fallback/platform-controlsPlatform defaults for uncovered controls · scope: checkbox · radio · date · time · file · toggle · switch “If the system defines no control for a need, use the platform's native element with system typography and square form; keep native semantics.”constraints: square form (ORB-1 still applies) · system type scale · mark the improvisation and report a gap if the need recurs
