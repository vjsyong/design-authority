## Design system

This product follows the **Triage design system**. A complete static kit is in
`design/`: the system package (tokens, core CSS/JS, fonts, icons, example
screens) plus full documentation in `design-docs/` (quickstart, component
catalogue, patterns, tokens, rules, the interaction standard, sanctioned
compositions, and what to do when the system has no answer).

Read the kit and build the UI to conform to it: use its components, tokens,
rules and patterns. Where the system has no answer, follow its fallback
guidance and prefer plain, token-conformant UI over inventing new visual
language.
