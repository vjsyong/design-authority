# driftexp — x05 blind review app

The guided, gated blind-review surface for experiment 05 (seed evolution).
Reviewers open a capability link, enter their name, and rate a shuffled set
of narrow 1–5 comparisons. Progress autosaves; resume by name.

- Built on the **Triage design system** (`authorities/triage/dist`, vendored
  byte-identical under `assets/`); validated with the pack's lint validator.
- Public but gated: unguessable capability path + reviewer name; every
  response carries `X-Robots-Tag: noindex, nofollow` and `robots.txt`
  disallows everything.
- Data lives in `data/` (never committed): `config.json` (capability token),
  `blindset/` (set + images + server-side key), `ratings.jsonl` (events).

## Run

    python3 app.py --port 8455

The startup line prints the local and public URLs (public host
`driftexp.seanyong.xyz` via the Cloudflare tunnel, systemd user unit
`x05-blind.service`).

## Review set

- Placeholder (build testing): `python3 tools/make_placeholders.py` —
  generates 6 synthetic pairs into `data/blindset/`; excluded from analysis.
- Real set: generated by the x05 experiment pipeline from sealed captures;
  each comparison is `{code, kind, prompt, left, right, scale}` and the
  code→condition mapping lives only in the server-side `key.json`.
  Generator: `docs/experiments/seed-evolution/tools/x05_blindset.py`
  (rev 2; reads `run/<id>/capture/` probes + screenshots for the 13
  checkpoints; renders the seed→H1 whole-screen steps plus per-handoff
  "new element vs established element" matches; order + orientation
  shuffled with a recorded seed; the mapping stays sealed until scoring
  ends). Rev 1 (all adjacent-checkpoint pairs) was replaced after a
  pixel audited showed the established surfaces render byte-identical
  from the first handoff on; its set/key are kept as `set-real-v1.json`
  / `key-real-v1.json`.

## Events (`ratings.jsonl`)

`{"event": "started"|"answer"|"comment", "name", "code", "rating", "note",
"text", "ts"}` — append-only; last answer per (name, code) wins.
