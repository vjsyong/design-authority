# Bookmarks — this session: a command palette

The product exists — source and screenshots in `reference/`. Add a command
palette:

- A keyboard-first surface: open with Ctrl/Cmd+K and from a visible control;
  type to search actions with fuzzy matching; arrow keys move the active
  item, Enter runs it, Escape closes.
- Actions cover the product's real operations (for example: add bookmark,
  search, sort, density, tag filters, edit mode, import) — the palette is
  another way into what exists, not a separate feature set.
- Recently used actions are remembered and offered first on an empty query.
- It must feel like the same product: palette surfaces, states and type come
  from the existing visual language.

QA hooks to add (keep all existing): `btn-palette` (the visible open
control), `command-palette` (root), `palette-input`, `palette-item` (one per
result row).

Everything existing keeps working. Where you deliberately change an existing
treatment, say so in your handoff. House process: follow any protocol
documents in `reference/` and the project's records. Finish runnable, with
`HANDOFF.md` and a commit.
