# Bookmarks — session 2: tags, bulk actions, and a real form

The app exists — read the source and the screenshots in `reference/` before
you start. This session:

- **Tag filtering.** A filter row of tag chips built from the tags in use
  (an "all" chip plus one per tag). Picking a chip narrows the list; picking
  it again (or an explicit reset) clears it. When a filter matches nothing,
  show a distinct empty state that explains the filter and offers a way
  back.
- **A completed add form.** Title required; URL required and validated as a
  plausible web address; tags entered as free text (comma separated).
  Errors are visible states on the form at the moment they matter.
- **Bulk actions.** Every row can be selected. With a selection active, a
  bulk bar shows how many items are selected and two actions: **add a tag to
  the selected bookmarks**, and **delete the selected bookmarks**. Bulk
  deletion requires a confirmation that states the consequence before it
  happens.
- **Selection surfaces.** Selected rows and the bulk bar belong to the same
  visual family as everything else — not a bolt-on.

QA hooks to add (keep all existing): `tag-filter`, `tag-chip`,
`filter-empty`, `bulk-select`, `bulk-bar`, `bulk-apply`, `bulk-delete`,
