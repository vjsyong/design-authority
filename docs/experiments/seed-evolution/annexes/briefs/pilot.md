# Rehearsal session (pre-flight dry run)

This is a pre-flight check of the environment, not a real deliverable.
Spend a few minutes at most.

1. Look around the workspace: `README.md`, `QA.md`, `serve.py`, and the
   `reference/` folder.
2. Make one small, real change: add a short "current state" section to
   `README.md` — three to five bullet points describing the project as it
   stands.
3. Run the app (`python3 serve.py --port 8090`), open it, confirm the page
   loads, then stop the server.
4. If this workspace provides house tooling (for example a `run-authority`
   script), exercise it: resolve one question and, if it supports filing,
   file one gap.
5. Run `git status` and commit your change with a short message.
6. Write `HANDOFF.md` with a one-line summary of what you did.

Stop when those steps are done.
