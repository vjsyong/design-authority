# Bookmarks — this session: an import wizard

The product exists — source and screenshots in `reference/`. Add a
multi-step import flow:

- Opened from the list screen. Steps: **source data** (paste or enter a
  list of title+URL(+tags) lines, or an exported bookmark list) → **field
  mapping** (which source fields map to title / URL / tags, shown as a
  table) → **validation and preview** (what will be imported, what is
  skipped and why) → **import** with progress while it runs, then a summary.
- Back / next navigation between steps; the flow can be abandoned at any
  step without side effects.
- Errors and skipped rows are visible states, not console noise.
- It must feel like the same product: the wizard, table and progress
  treatments come from the existing visual language.

QA hooks to add (keep all existing): `btn-import` (the entry point),
`import-wizard` (root), `wizard-next`, `wizard-back`, `mapping-table`,
`wizard-progress`, `import-submit`.

Everything existing keeps working. Where you deliberately change an existing
treatment, say so in your handoff. House process: follow any protocol
documents in `reference/` and the project's records. Finish runnable, with
`HANDOFF.md` and a commit.
