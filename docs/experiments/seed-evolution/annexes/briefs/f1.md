# Bookmarks — session 1: the core screen

Build the first working version of **Bookmarks**, a small personal bookmarks
manager. This session: the app shell, the bookmark list, the primary action,
and bookmark cards.

Requirements:

- Single-page client-side app. `python3 serve.py --port 8090` runs it (any free port works; 8080 is often busy); data
  lives in localStorage under `bookmarks.v1` (`QA.md` has the details).
  Plain HTML/CSS/JS — no build step, no external dependencies.
- The list shows each bookmark's title and URL, and its tags when it has
  any. Bookmarks appear immediately after being added and survive reloads.
- A first-run empty state (no bookmarks yet) that explains what this is and
  offers the way to add the first bookmark.
- The primary action opens a small form to add a bookmark (title, URL, and
  optional tags); saving adds it to the list and closes the form.
- Give the shell room to grow — a header area and a place navigation can
  live later.

QA hooks your session must add (keep anything that already exists):
`btn-add-bookmark` (the primary add action), `bookmark-list`,
`bookmark-card` (one per bookmark), `bookmark-title`, `bookmark-url`,
`empty-state`, `form-add`, `input-title`, `input-url`, `input-tags`,
`submit-add`.

Check your work: run the app and add a few bookmarks through the UI.

House process: follow any protocol documents in `reference/` and the
project's records. Finish with the app runnable, `HANDOFF.md` updated, and
your work committed.
