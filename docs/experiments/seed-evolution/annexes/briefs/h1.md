# Bookmarks — this session: search, sorting, and density

The product exists — read the source and the screenshots in `reference/`
first; your work must belong to it (same patterns, same visual language).
Add to the list screen:

- **Search.** A search field that filters the list as you type (title and
  URL at minimum).
- **Sorting.** A sort control (e.g. title A–Z / Z–A, date added newest /
  oldest).
- **Density.** A density control (comfortable / compact) that changes how
  much room list rows take.
- These combine with each other and with the existing tag filter — check
  the combinations, including a search that matches nothing.

QA hooks to add (keep all existing): `search-input`, `sort-control`,
`density-control`.

Everything existing keeps working. Where you deliberately change an existing
treatment, say so in your handoff. House process: follow any protocol
documents in `reference/` and the project's records. Finish runnable, with
`HANDOFF.md` and a commit.
