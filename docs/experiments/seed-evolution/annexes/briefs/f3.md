# Bookmarks — session 3: editing, deleting, and small screens

The app exists — source and screenshots in `reference/`. This session:

- **Edit flow.** Every bookmark can be opened for editing (title, URL, tags)
  and saved; the edit form validates exactly like the add form, and saving
  applies immediately.
- **Tag editing.** Tags can be added or removed on a bookmark in the edit
  flow; the filter row reflects the changes afterwards.
- **Single delete.** Each bookmark can be deleted on its own, with a
  confirmation that states the consequence.
- **Responsive details.** The list, forms, bulk bar and confirmation all
  work at phone width without horizontal scrolling or clipped controls.
