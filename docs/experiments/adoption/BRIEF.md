# Task: a small recipe-box app, under the repository you find

You are on a fresh sandboxed machine. You have:

- an empty working directory (this one),
- network access (public repositories and packages),
- nothing else. No human will answer questions.

Someone told you that the public repository `https://github.com/vjsyong/design-authority`
exists and that teams use it so coding agents build software that actually
holds up. Clone it, read it, and set up whatever it requires on this machine.
Then build what is asked below, in this directory.

## The app: a recipe box

A static web app (opening `index.html` works; no server required):

- a list of recipes: name plus a short note; add and delete recipes;
- an empty state when there are no recipes yet;
- a confirmation when a recipe is saved;
- a way to mark a recipe "tried";
- when I mark a recipe tried, a small confetti burst should play. It should
  feel like a deliberate part of this app's own character, not generic;
- overall it should look and behave like the system intends, not like
  default browser furniture.

## How to work

Work under the repository's own rules for building software with it: read
how its documentation says agents should work, follow that, and check your
work the way it says to check it. If something above is not covered by what
the system provides, handle that the way its documentation prescribes.

Leave the repository checkout itself untouched: pull and read, never commit
or push.

## Deliverable

When you are done, write `DONE.md` in this directory containing:

- what you set up on the machine (exact commands and outcomes);
- what you built, and which parts of the system you used for it;
- anything the system did not define that you had to improvise, and what you
  did about that;
- the results of any checks you ran, with their raw output pasted in.

Then give a short summary. Stop when this file's requirements are met.
