# dominion · Gestalt model (Phase 4)

Derived from `00-evidence-inventory.md` (7 official Design Standard pages +
history + content guides; 10 raw extracts). Draft for **Gate 1**. Character
only — no official symbols, wordmark or arms reproduced anywhere (Crown-
controlled marks stay out; this is a derived grammar for a future authority).

## The read

The Federal Identity Program reads as **ceremonial restraint**: one red flag
accent over disciplined black Helvetica on white, bilingual by construction,
measured from a single master object, and governed by plain language. It is
austere not because it is empty, but because every element is either fixed,
measured, or gated — a closed grammar of few parts used consistently.

## Visual principles

1. **One red, ceremonial.** FIP red is confined to the flag accent and
   identity moments; everything else is black, white, pewter grey. No second
   accent exists.
2. **The mark is the measure.** All sizing is relative to the wordmark
   (letter-"C" height clear space; flag height; half-arms width) — the system
   scales as one lockup ratio, never fixed absolutes.
3. **Helvetica discipline.** Four weights as roles: Light = stationery,
   Regular = most communications, Medium = signage/vehicles/websites, Bold =
   signage/vehicle messages. Same typeface everywhere; hierarchy by weight
   and structure, not colour.
4. **Bilingual by structure.** English and French pair side-by-side in every
   signature (fixed order rules; over-under fallback under width pressure);
   equality is structural, not optional.
5. **Fixed bookends.** Four canonical positionings; on websites the signature
   sits top-left and the wordmark bottom-right — identity frames the page.
6. **Plain language mandated.** "Plain, non-bureaucratic language, functional
   graphic design, systems approach" — task-first, scannable, gender-
   inclusive, WCAG-referenced; official statements carry mandated phrasing.
7. **A closed grammar.** Two official symbols; everything else approval-gated;
   marks never redrawn; animation must resolve to the static approved form.
8. **Rule over ornament.** Structure is communicated with alignment, spacing
   and rules; nothing decorative is specified anywhere.
9. **Ceremonial red vs safety red.** Pantone 032 (identity) and 185 (signage
   semantics) are distinct devices with distinct licences.
10. **Rectilinear by nature.** Every figure in the standard is rectangular;
    no corner treatment or container softness is defined anywhere.

## Colour character

| token | value | role | status |
|---|---|---|---|
| FIP red | Pantone 032 · RGB 235,45,55 · hex `#EB2D37` (conversion) | flag accent, identity moments | OBSERVED (RGB) / hex converted |
| Black | Process black `#000000` | type, arms, structure | OBSERVED |
| White | `#FFFFFF` | standard background | OBSERVED |
| Pewter grey | Pantone 429 · RGB 150,150,150 · `#969696` (conversion) | ministerial arms only | OBSERVED |
| Signage set | light grey 428 · dark grey 432 · yellow 109 · blue 301 · green 348 · safety red 185 | signage technical specs only | OBSERVED (not for UI) |

Character: ink-on-paper SO governmental that colour is a ceremony, not a
style. Reversed colourway (white on black) exists and is recommended for
large formats.

## Typographic character

- Helvetica exclusively for signatures and titles; the wordmark's Baskerville
  heritage is not ours to use.
- Weight roles as above; titles 2–4 words, "Canada" required, no special
  characters.
- No sizes/leading/tracking anywhere — carried UNDEFINED; the tile will set
  a plain, generous reading rhythm and declare it.
- Tile stand-in: Arimo (metric Helvetica-class) — declared on the tile.

## Shape language

Rectilinear, rule-based, no radii. Identity geometry is heraldic (flag/arms)
but UI grammar derived from it is: rectangles, bars, rules, measured space.
Dos/don'ts: horizontal only, never angled, never altered, generous open
space.

## Density

Austere and structured: heavy margins, black-on-white reading, structure via
alignment. Density values not specified — the tile interprets "generous,
open space" from the clear-space culture.

## Surface treatment

White ground; black text; red confined to the flag element; reversed
(white-on-black) variant for large formats; "no visually conflicting
backgrounds". No elevation/shadow language (UNDEFINED).

## Imagery treatment

Protectionist posture: no photography/illustration style is defined;
non-official logos only in formal partnerships; social icons only as links.
Imagery is mostly *absence* — carried as a real property of the system.

## Layout rhythm

Fixed-corner framing (signature top-left, wordmark bottom-right on web);
four canonical pairings; bilingual pairing as the recurring structural
device; ministerial arms centred above.

## Motion character

Motion is gated and end-state-fixed: animated identity must resolve to the
static approved form; musical signature = first 4 notes of O Canada, 1.5s.
No easing/duration language for UI (UNDEFINED).

## Visual hierarchy

Weight + space + structure; official titles as the focal element; bilingual
equality; red reserved for ceremony so it never competes with content.

## What dominion would avoid (from the evidence)

Decorative colour; soft/playful shapes; unofficial marks; slogan-style use of
the identity in headlines; angled or altered anything; translated wordmark;
bureaucratic language (plain language is mandated); visual conflict behind
marks.

## Carried UNDEFINEDs (deliberate)

Hex codes for marks (consumers convert; we converted mechanically) · UI
states & interactivity (deferred by the standard to Canada.ca spec, not
fetched — not imported) · grids & margins · type sizes · feedback semantics ·
motion timing beyond the musical signature · imagery style.
